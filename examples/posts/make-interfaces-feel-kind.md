好的界面，会在每次操作之后给出明确的回答。点击之后发生了什么，失败之后还能做什么，都值得认真设计。

## 从一个按钮开始

当读者按下「复制」，一声轻轻的「已复制」就足够了。如果操作需要等待，按钮应该表达正在进行，而不是让人不断重复点击。

```typescript
async function copyArticleLink(url: string) {
  try {
    await navigator.clipboard.writeText(url);
    return '链接已复制';
  } catch {
    return '暂时无法复制，请从地址栏手动复制';
  }
}
```

## 空白也需要设计

比起只有一句「暂无数据」，一条清楚的解释和一个可执行的入口，会让人更安心。

| 场景 | 提示 | 下一步 |
| --- | --- | --- |
| 搜索没有结果 | 换一个关键词试试 | 清除搜索 |
| 文章暂未发布 | 这里的文字正在准备中 | 返回首页 |
| 搜索没有结果 | 暂时没有找到这段文字 | 清除筛选，查看全部文章 |

## 对不顺利的时刻多想一步

网络可能暂时断开，图片也可能加载失败。把这些状态当成正常的一部分，界面就能更从容。

1. 说明发生了什么。
2. 保留已经输入的内容。
3. 给出重试或返回的选择。
